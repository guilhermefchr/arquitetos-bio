# Tekton Digital — Arquitetos Bio

Landing page premium e formulário conversacional interativo desenvolvido para a **Tekton Digital** (Guilherme), focado em escritórios e arquitetos autônomos.

## 🚀 Funcionalidades

- **Hero Editorial & Minimalista**:
  - Grid de 12 colunas responsivo no desktop (1280px).
  - Fotografia com iluminação cinematográfica e transição gradual de fundo.
  - Tipografia fluida com Red Hat Display.
- **Formulário Conversacional em 3 Etapas**:
  1. *Sobre você* (Arquiteto autônomo, Sócio de escritório, Outro).
  2. *Como chegam seus projetos hoje?* (Indicação, Instagram, Google, Tráfego pago, Outros).
  3. *Seus dados* (Nome e WhatsApp com validação).
- **Integração com Webhook Make**:
  - Disparo de payload estruturado em JSON com dados do lead e parâmetros UTM.
- **Redirecionamento Dinâmico para WhatsApp**:
  - Geração de link com mensagem personalizada para Guilherme (`11 99550-7196`).

## 🛠️ Tecnologias

- **HTML5 Semântico**
- **CSS3 Vanilla** (Grid System, Flexbox, Tokens CSS, Responsivo mobile-first)
- **JavaScript Vanilla** (State Machine, Validação, Fetch API para Webhook)
